The Personal Book Manager (A Simple Assignment) 


“Simple can be harder than complex. But it’s worth it because once you get there, you can move mountains.” 
We’re inviting you to build something deceptively simple. A personal space for readers — to log their books, reflect on their habits, and rediscover their favorite authors. 
At its core, this is a technical challenge. But more importantly, it's a design of thought. 
What to Build 
Build a full-stack Personal Book Manager using the MERN stack, with Next.js powering the frontend. 
The idea is simple: 
● A person should be able to sign up, log in, and manage a personal collection of books. ● They should feel like this tool was made just for them — intuitive, elegant, and quietly powerful. 
Core Features 
1. Authentication 
● Sign up, log in, log out — all securely. 
● Use JWT for authentication. 
● Protect routes and user data thoughtfully. 
2. Book Collection 
Allow users to: 
● Add books (title, author, tags, status) 
● Edit or delete them 
● Filter the collection by tag or reading status

3. Dashboard 
Surface insight, not noise: 
● Total books in collection 
● List of books 
● Ability to mark them as read, reading or completed 
Let the data speak gently — no clutter, just clarity. 
Tech to Use 
● Frontend: Next.js (App Router encouraged) 
● Styling: Tailwind CSS or your own handcrafted CSS 
● Backend: Node.js + Express or Next.js API routes 
● Database: MongoDB 
● Auth: JWT 
What You’ll Submit 
● A GitHub repo with: 
○ A clear README.md 
○ Working code and project structure 
○ .env.example file for local setup 
● Deployed Link (Vercel + MongoDB Atlas is great) 
Timeframe 
3 days. 
It won’t take more than 6–8 hours if you truly understand the stack. 
Technically it is just a to-do list concept extended to reading list. 
⚠ Important 
● Use only official documentation (React.dev, MongoDB docs, etc.) 
● No ChatGPT, Copilot, or code generators. This is your thinking, not their shortcuts. ● Focus on clarity, not complexity. 
● Be proud enough of your code that you'd present it on stage.
